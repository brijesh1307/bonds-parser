# Real deal slips (reference only)

Drop real bond deal slips here (PDF / Excel / email / scans) to build parser templates.

- Mask sensitive data first: counterparty names, account / SGL / DP / client IDs, dealer names.
  Keep the **layout, labels and number formats unchanged**, because those are what the parser learns from.
- Everything in this folder except this README is git-ignored so real slips are never committed.
